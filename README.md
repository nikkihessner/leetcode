# 🧠 LeetCode: Learning in Public

This is my evolving archive of LeetCode solutions — some elegant, some stubborn — written to sharpen my problem-solving skills, develop pattern fluency, and document what I’m learning out loud.

I’m not trying to grind for perfection. I’m trying to think clearly, code better, and show that I can build real understanding — with a little help from AI and a lot of persistence.

---

## 🧰 What’s Inside

- 🧪 : Unit tests for each solution, often including edge cases
- 🧠 : My initial (and sometimes deeply stubborn) solutions
- 🤖 : LLM-enhanced insights or cleaner versions, when I bring in a co-pilot
- 📝 Write-ups and docstrings explaining tricky logic or what I learned
- 📂 Folders by date () and topic area (coming soon)

---

## 💬 Why I'm Doing This

I left mechanical engineering and got my MSCS during a chaotic few years. I’m now building toward a career in software development by doing the actual work — solving problems, documenting progress, and trying to balance “playing the game” with developing *real* intuition and skills.

This repo isn’t just for recruiters. It’s for me. And maybe for you, if you’re walking a similar road.

---

## 🤖 On Using AI

I regularly use tools like ChatGPT to:
- Check edge cases
- Refactor messy logic
- Get unstuck
- Learn new patterns

But I don’t just copy-paste. If I use AI to improve a solution, I include it in a separate file and explain what changed.
